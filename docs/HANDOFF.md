## How to work (unchanged)

- `npm run typecheck` and `npm run smoke` must both pass before any task is "done".
  `smoke` builds + boots the game in headless Chromium and fails on any runtime error —
  it is the regression net.
- One task, one commit. Conventional-commit style.
- Read before you write. Prefer additive change. Leave explicit `TODO`s for anything
  unfinished — never ship a stub that looks complete.
- Hard constraints hold: zero network calls, non-lethal, everything procedural,
  forgiving by design.

### Environment notes (learned the hard way)

- **No physical Android device is attached.** An Android SDK is at
  `%LOCALAPPDATA%\Android\Sdk` (platforms 34/35/36, build-tools 34/35/36, two AVDs:
  `Medium_Phone_API_35`, `Pixel_6_API_34`). `android/local.properties` (gitignored) points
  Gradle at it.
- Use the SDK's `platform-tools\adb.exe` explicitly — there is an **older `adb` (v32) on
  PATH at `C:\Android\adb`** that fights the SDK's `adb` (v41) over the server port.
- Headless emulator boot with `-gpu swiftshader_indirect` is extremely slow and did not
  finish within the time budget. If you retry: try `-gpu host` first, give it 5+ minutes,
  and poll `adb shell getprop sys.boot_completed`.
- Verifying **live motion** through the Claude Code Browser pane is unreliable —
  `requestAnimationFrame` suspends whenever the pane is hidden, so the game loop freezes
  during long tool evals. Instant state ops (debug menu, save/reload, quality switch) do
  verify fine. Trust `smoke` for "the loop runs without throwing".
